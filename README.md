# Sistema de Cadastro de Alunos — Escola XYZ

Projeto introdutório em Java usando Programação Orientada a Objetos (POO).

## Requisitos atendidos
- Classe `Aluno` com nome, endereço residencial, telefone, e-mail e matrícula.
- Classe `Principal` para iniciar e testar o programa.
- Instanciação de um objeto `Aluno` com `new`.
- Atribuição de valores aos atributos e exibição dos dados.
- Métodos getters e setters para consultar e atualizar os dados.
- Método `exibirDados()` para apresentar o cadastro.

## Arquivos
- `Aluno.java`: definição da classe e seus atributos e métodos.
- `Principal.java`: método `main`, criação do objeto e teste.
- `README.md`: instruções de execução.

## Como executar

É necessário ter o JDK (Java Development Kit) instalado.

### Pelo terminal
1. Abra o terminal na pasta onde estão `Aluno.java` e `Principal.java`.
2. Compile os arquivos:

   ```bash
   javac Aluno.java Principal.java
   ```

3. Execute o programa:

   ```bash
   java Principal
   ```

### Em uma IDE (NetBeans, Eclipse ou IntelliJ IDEA)
Crie um projeto Java, adicione os arquivos `Aluno.java` e `Principal.java` ao pacote padrão e execute a classe `Principal`.

## Observação
Os dados utilizados são fictícios e servem apenas para demonstrar o funcionamento do programa.
